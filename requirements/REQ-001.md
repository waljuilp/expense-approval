# REQ-001

## Business objective

Ensure expenses over €1,000 are reviewed by a manager before approval, while allowing lower-value expenses to be automatically approved.

## User story

As an employee, I want high-value expenses to require manager approval so that large expenses are reviewed before approval.

## Functional requirements

- Evaluate the expense amount in euros against the €1,000 threshold.
- Expenses up to and including €1,000 are eligible for automatic approval; whether it is mandatory is an open question.
- Expenses over €1,000 must not be approved without manager approval.
- Preserve the existing requirements that a description is mandatory and an amount must be greater than zero.
- The existing application is browser-only and has no manager identity or role verification. A trusted way to establish manager authority is needed before the manager-approval rule can be enforced.

## Acceptance criteria

### AC-001: Below the threshold

**Given** a valid expense of €999.99  
**When** its amount is evaluated against the approval threshold  
**Then** it is eligible for automatic approval and manager approval is not required by this threshold rule.

### AC-002: At the threshold

**Given** a valid expense of exactly €1,000.00  
**When** its amount is evaluated against the approval threshold  
**Then** it is eligible for automatic approval and manager approval is not required by this threshold rule.

### AC-003: Above the threshold

**Given** a valid expense of €1,000.01  
**When** the expense is submitted  
**Then** it is not automatically approved and requires manager approval before it can become approved.

### AC-004: Manager approval

**Given** a submitted expense over €1,000 awaiting manager approval  
**When** an authorized manager approves it  
**Then** the expense becomes approved.

### AC-005: Unauthorized approval

**Given** a submitted expense over €1,000 awaiting manager approval  
**When** a person who is not authorized as its manager attempts to approve it  
**Then** the expense does not become approved.

### AC-006: Invalid amount

**Given** an expense with an amount of zero or less  
**When** the employee attempts to submit it  
**Then** the expense is not submitted or approved.

### AC-007: Missing description

**Given** an expense with no description  
**When** the employee attempts to submit it  
**Then** the expense is not submitted or approved.

## Error and boundary conditions

- Test €999.99, €1,000.00 and €1,000.01 separately; exactly €1,000 is not above the threshold.
- Amounts must be positive; the existing form accepts euro amounts in cents.
- A failed or unverified manager-approval attempt must not result in approval.
- Whether existing submitted or approved expenses are subject to the new rule is not specified.

## Risk

**HIGH** — This change introduces authorization requirements for financial approvals. The current browser-only application cannot verify manager identity or enforce authorization against an untrusted user.

## Open questions

1. Must all valid expenses of €1,000 or less be automatically approved on submission, or is automatic approval optional? This affects the current rule that new expenses start as `SUBMITTED`.
2. How is an authorized manager identified and assigned to an expense? Can a manager approve their own expense?
3. Is a trusted backend and authentication/authorization mechanism now permitted, despite the MVP's original browser-only constraint? If not, how is manager approval expected to be enforced?
4. Can managers reject high-value expenses, and are rejection reasons or notifications required?
5. Does the rule apply to existing expenses, and what should happen to already-approved expenses over €1,000?
