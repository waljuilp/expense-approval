# REQ-001

## Business objective

Ensure that high-value expenses receive manager approval before they
are approved.

## User story

As an employee
I want high-value expenses to require manager approval
So that large expenses are reviewed before approval.

## Functional requirements

### FR-001

Expenses up to and including €1,000 can be automatically approved
without manager approval.

### FR-002

Expenses over €1,000 require manager approval.

### FR-003

Expenses requiring manager approval must have a status that clearly
indicates that approval is pending.

## Acceptance criteria

### AC-001

Given an expense amount of €999.99
When the expense is submitted
Then manager approval is not required.

### AC-002

Given an expense amount of exactly €1,000.00
When the expense is submitted
Then manager approval is not required.

### AC-003

Given an expense amount of €1,000.01
When the expense is submitted
Then manager approval is required.

### AC-004

Given an expense amount greater than €1,000
When the expense is submitted
Then the expense status indicates that manager approval is pending.

## Error and boundary conditions

The €1,000 approval threshold is an important boundary condition.

The implementation must correctly handle:

- €999.99 → manager approval is NOT required
- €1,000.00 → manager approval is NOT required
- €1,000.01 → manager approval IS required

The business rule is:

amount > 1000 → manager approval required

The rule must NOT be interpreted as:

amount >= 1000

## Risk

MEDIUM

Reason:

The change modifies business logic controlling expense approval but
does not introduce authentication, personal data handling or other
high-risk functionality.
